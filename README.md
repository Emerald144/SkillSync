# SkillSync – Peer-to-Peer Knowledge Sharing Platform

**SkillSync** is an AI-powered peer-to-peer knowledge-sharing platform designed to connect learners with suitable mentors and learning partners based on their skills, interests, learning goals, availability, and experience level.

The platform encourages users to both **learn and share knowledge**. Users can exchange skills with each other or use platform tokens to reward knowledge providers. SkillSync also includes ratings, reviews, reputation scores, achievements, and reporting mechanisms to create a trusted and collaborative learning community.

## Key Features

* User registration, login, and profile management
* Skill-based teacher and learning-partner search
* AI-based learning partner matching
* Peer-to-peer skill exchange
* Token-based reward system
* Ratings and reviews
* Reputation and achievement system
* Communication and learning sessions
* User reporting and moderation
* Admin dashboard and user management

## Technology Stack

* **Frontend:** HTML, CSS, JavaScript, JSP
* **Backend:** Java Servlet, JDBC, JavaBeans
* **Architecture:** MVC
* **Database:** MySQL
* **Server:** Apache Tomcat
* **IDE:** Eclipse / IntelliJ IDEA

## Project Goal

SkillSync aims to make learning more **accessible, collaborative, and trustworthy** by helping people find suitable learning partners while encouraging them to contribute their own knowledge to the community.
